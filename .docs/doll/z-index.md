# Порядок отрисовки и надевания вещей

Создан: 2026-11-16 09:36

Правила, по которым кукла решает, какая вещь рисуется поверх какой и какая вещь заменяет надетую. Это основа логики надевания: экран куклы, конфиг датасета и проверка при сборке опираются на этот документ.

## Термины

| Термин | Что это | Кто видит |
|---|---|---|
| **Уровень** | Место категории в общем порядке отрисовки куклы. | только логика |
| **Порядок надевания** | Очерёдность, в которой пользователь выбрал надетые вещи. | только логика |
| **Группа** | Набор категорий, которые исключают друг друга сверх лимита. | только логика |
| **Лимит** | Сколько вещей группы можно надеть одновременно. | только логика |
| **Слот** | Якорная точка вещи на фигурке: обувь, ноги, пояс, торс, шея, руки, голова. | только логика |
| **Раздел** | Место категории в каталоге. | пользователь |

Уровень, группа и слот — независимые свойства. Из одного нельзя вывести другое: у колготок слот «пояс», а уровень между бельём и носками.

## Правила отрисовки

1. **Уровни упорядочены.** Список уровней задаётся снизу вверх, от фигурки к верхней одежде. Вещь более высокого уровня всегда рисуется поверх вещи более низкого, в какой бы очерёдности их ни надевали. Рубашку нельзя надеть поверх пиджака.
2. **Внутри уровня решает порядок надевания.** Вещи одного уровня рисуются в порядке выбора: надетая позже — сверху. Выбрали футболку, потом водолазку — водолазка поверх футболки; наоборот — наоборот.
3. **Повторное надевание кладёт вещь наверх.** Сняли и снова надели — вещь становится последней в порядке надевания своего уровня.
4. **Уровень задаётся категорией, а не вещью.** Все вещи категории стоят на одном уровне.
5. **Фигурка — ноль.** Все вещи рисуются над ней передней плоскостью и под ней задней.

## Вычисление z-index

```
z_front = позиция уровня · K + порядок надевания внутри уровня
z_back  = −z_front
z_фигурки = 0
```

- **Позиция уровня** — номер уровня в списке, начиная с 1. Числа в конфиге не хранятся: уровень добавляется строкой в нужное место списка, и остальные сдвигаются сами.
- **K** — множитель, который больше максимального числа вещей на одном уровне. Порядок надевания никогда не перескакивает на следующий уровень.
- **Задняя плоскость** не хранится отдельно и всегда равна минус передней. Чем дальше вещь от тела, тем дальше её спинка за фигуркой. Это распространяется и на порядок надевания: у водолазки, надетой поверх футболки, перед выше, а спинка дальше.

## Правила замены

1. Каждая категория входит ровно в одну группу. Если группа не указана, это собственная группа категории с лимитом 1.
2. Пока лимит не исчерпан, новая вещь просто надевается.
3. Когда лимит исчерпан, новая вещь заменяет самую раннюю надетую вещь этой группы. Заменённая вещь возвращается в каталог.
4. Вещи разных групп не заменяют друг друга, даже если стоят на одном уровне или пересекаются на кукле. Пальто можно надеть и на голое тело, и поверх кофты.
5. Снятие вещи не меняет уровни и порядок остальных.

Группа и уровень решают разные задачи. Уровень отвечает на вопрос «кто над кем», группа — «кто кого вытесняет». Колготки и носки стоят на разных уровнях (носки всегда поверх), но колготки и чулки — одна группа (надеть можно только что-то одно).

## Уровни

Снизу вверх. Курсивом — зарезервированные места, которые пока не используются.

| # | Уровень | Категории | Группа (лимит) |
|---|---|---|---|
| 1 | бельё | трусы, бюстгальтер, бельевая майка | у каждой своя (1) |
| 2 | колготки | колготки, чулки | колготки (1) |
| 3 | носки | носки, гольфы | носки (1) |
| 4 | обувь | тапки, туфли, ботинки, сапоги | обувь (1) |
| — | *заправленное* | *вещи торса в режиме «заправлен»* | |
| 5 | низ | леггинсы, брюки, юбка, шорты | низ (1) |
| 6 | нательное | майка, футболка, водолазка | нательное (2) |
| 7 | рубашки | рубашка, блузка | рубашки (1) |
| 8 | галстук | галстук | своя (1) |
| 9 | платья | платье, сарафан, комбинезон | платья (1) |
| 10 | свитеры | свитер, кофта | свитеры (1) |
| 11 | поверх свитера | кардиган, жилет | накидки (1) |
| 12 | жакеты | пиджак, жакет | жакеты (1) |
| 13 | верхняя | плащ, куртка, пальто, шуба | верхняя (1) |

Почему так:

- **Носки над колготками.** Носки надевают на колготки, но не наоборот.
- **Обувь над носками и под низом.** Обувь одна и всегда поверх носков. Брюки, юбка и длинное платье ложатся поверх обуви.
- **Нательное и рубашки разделены.** Футболку и водолазку можно надеть в любом порядке, но рубашка всегда поверх них.
- **Галстук отдельным уровнем.** Рубашка, надетая после галстука, всё равно ляжет под него.
- **Платья над торсом.** Рубашку и галстук можно надеть под сарафан.
- **Кардиган и жилет над свитерами.** Их надевают поверх свитера и кофты, а друг друга они исключают.

## Примеры

| Действия пользователя | Результат снизу вверх |
|---|---|
| футболка → водолазка | футболка, водолазка |
| водолазка → футболка | водолазка, футболка |
| рубашка → футболка | футболка, рубашка (уровень сильнее порядка) |
| колготки → носки → туфли | колготки, носки, туфли |
| носки → колготки | колготки, носки (уровень сильнее порядка) |
| колготки → чулки | чулки (заменили колготки, группа «колготки», лимит 1) |
| туфли → сапоги | сапоги (заменили туфли) |
| майка → футболка → водолазка | футболка, водолазка (майка заменена, лимит 2) |
| галстук → рубашка | рубашка, галстук |
| пиджак → жакет | жакет (заменил пиджак) |
| свитер → кардиган → жилет | свитер, жилет (жилет заменил кардиган) |

## Представление в конфиге

Уровни, группы и разделы описаны в `categories.json` рядом с папками датасета. Категория ссылается на них по id.

```json
{
  "levels": ["underwear", "tights", "socks", "shoes", "bottoms", "undershirts",
             "shirts", "tie", "dresses", "sweaters", "oversweaters", "jackets", "outerwear"],
  "groups": {
    "tights": { "limit": 1 },
    "undershirts": { "limit": 2 }
  },
  "sections": [
    { "id": "underwear", "title": "Бельё" }
  ],
  "categories": {
    "трусы": { "slot": "waist", "level": "underwear", "section": "underwear" },
    "футболка": { "slot": "torso", "level": "undershirts", "group": "undershirts", "section": "tops" }
  }
}
```

## Инварианты, которые проверяет сборка

- Каждой папке категории соответствует запись в `categories` и наоборот.
- `slot` входит в список: `feet`, `legs`, `waist`, `torso`, `neck`, `arms`, `head`.
- `level`, `group` и `section` ссылаются на существующие записи.
- id уровней уникальны.
- У каждой группы `limit ≥ 1`.
- В каждом уровне, группе и разделе есть хотя бы одна категория.
- Имена папок в нормализации NFC.

Сборка падает со списком всех нарушений сразу.

## Вне рамок

- **Заправленное.** Режим «заправлен» переносит вещь торса на отдельный уровень под низом. Место в списке зарезервировано, правила появятся позже.
- **Крепления.** Брошь, значок, зажим для галстука, ремень берут z-index носителя с небольшой добавкой и уходят в каталог вместе с ним.
- **Аксессуары** шеи, рук и головы получат свои уровни, когда появятся в датасете. Черновик из IDEA.md, снизу вверх над верхней одеждой и под ней:
  - *под верхней* (между жакетами и верхней): внешний воротник, бусы, шарф в режиме «под верхней», часы, браслеты;
  - *поверх верхней*: шарф в режиме «поверх», перчатки, сумка;
  - *голова* (самый верх): очки, серьги, ободок, шапка. Уши шапки, свисающие до пояса, ложатся поверх пальто.

  Одинаковые вещи (двое бус, два браслета) — один уровень и порядок надевания, отдельных правил не нужно.
- **Запреты между группами.** Платье и юбка, комбинезон и брюки сейчас совместимы: юбка просто ложится под платье. Если это начнёт мешать, добавим явное поле `excludes`.
- **Переопределения у вещи.** Все вещи категории живут по правилам категории.
- **Сохранение образов.** Порядок надевания — часть состояния образа, сохранять его придётся вместе с вещами.
