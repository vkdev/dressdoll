# Дискотека: стиль лучей в настройках

Создан: 2026-11-17 17:30

Часть 2 из 2. Продолжает [часть 1](plan_part_1.md): стиль лучей переезжает из константы `DISCO_BEAM_STYLE` в настройки.

## Что видит пользователь

- На экране «Настройки» под темой — раздел «Дискотека» с двумя вариантами: «Бумажные конусы» (ровные цветные конусы, по умолчанию) и «Мягкий свет» (лучи в дымке, края растворяются).
- Выбор применяется сразу и сохраняется между запусками.

## Как устроено

- Модули `:disco:api` и `:disco:impl`. В api — `enum BeamStyle { PAPER, SOFT }` и `DiscoSettingsRepository`: `beamStyle: StateFlow<BeamStyle>`, `setBeamStyle(style)`. Значение по умолчанию `PAPER` до чтения с диска: режим при запуске выключен, мигнуть нечему.
- `:disco:impl` — Preferences DataStore `disco`, запись в фоне, сбой чтения и записи не роняет приложение (как `ThemeSelectorImpl`). Тесты на файле во временной папке.
- Непрозрачность подкраски по стилю — в `:doll:impl`, не в api: это отрисовка. `DiscoConfig.kt` удаляется.
- `DollScreen` читает стиль из репозитория. Стиль меняется только на экране настроек, поэтому достаточно обычной рекомпозиции при возврате.
- Экран настроек (`:settings:settings-theme:impl`) зависит от `:disco:api`. Карточка варианта — новый компонент темы `OptionCard(title, selected, onClick, supportingText, leading)`: `SelectableCard` с заголовком, пояснением и радиокнопкой. На нём же собирается карточка «Как в системе».

## Элементы темы

- `OptionCard` в каталоге [theme-elements.md](../../android/theme-elements.md).
