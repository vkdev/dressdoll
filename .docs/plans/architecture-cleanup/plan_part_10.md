# Дневная и ночная палитры без ThemeIds; заметки к датасету

Создан: 2026-11-17 22:30

Часть 10 из 10. Независима от остальных; если делается вместе с [частью 8](plan_part_8.md), правки `ThemePalette` идут в `:theme:api` после разделения.

## Зачем

- Правило «Как в системе» знает id двух палитр через `ThemeIds`. Им пользуются `resolvePalette`, значение по умолчанию в `ThemeSelectorImpl` и превью «день/ночь» в разделе темы, а палитры «Корица» и «Диско» объявляют свой id из общего объекта, а не сами.
- `BitmapDecoder` знает о вёрстке потребителей: размер уменьшения картинки каталога выведен из ширины шторки (640 dp, две колонки), mipmap — из масштаба куклы в альбомной ориентации.

## Принятые решения

- Палитра сама объявляет роль: `ThemePalette.systemDefault: SystemDefault?` (`LIGHT`, `DARK`, по умолчанию `null`). «Корица» — `LIGHT`, «Диско» — `DARK`.
- `resolvePalette`, значение по умолчанию (палитра с ролью `LIGHT`) и превью «день/ночь» ищут палитру по роли. `ThemeIds` удаляется, «Корица» и «Диско» объявляют свои id сами, как остальные палитры.
- Контрактный тест палитр проверяет роль; отдельный тест в `:theme:impl` — что среди палитр ровно одна `LIGHT` и одна `DARK`.
