# Планы

Правила работы с планами:
- План лежит в `.docs/plans/<plan_name>/plan_part_N.md`.
- В каждой части указаны дата и время создания.
- Выполненные шаги в плане вычёркиваются (`~~…~~`).
- Полностью выполненный план удаляется вместе со строкой здесь.
