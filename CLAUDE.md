# Правила работы

## Git
- Всегда добавляй в git (`git add`) новые файлы, которые создаёшь, кроме тех, что исключены через `.gitignore`. Добавлять = индексировать; коммитить только по просьбе пользователя.

## Планы
- Сохраняй планы в `.docs/plans/<plan_name>/plan_part_N.md`.
- `.docs/plans/README.md` — навигация по всем планам: таблица с названием, датой создания, ссылками на части и статусом. Обновляй её при создании, изменении и удалении плана.
- В каждую часть плана добавляй дату и время создания (`Создан: YYYY-MM-DD HH:MM`).
- После выполнения части плана (или шага) вычёркивай сделанное в плане (`~~…~~`) и обновляй статус в README.
- После полного выполнения плана удаляй его папку и строку в README.

## Элементы темы Android
- `.docs/android/theme-elements.md` — каталог переиспользуемых элементов темы: токены (фигуры, отступы, размеры, линии), иконки, компоненты.
- Экраны собирают из элементов каталога. Если нужного нет, добавляй его в тему и в каталог, а не делай локальную копию в модуле экрана.
- Обновляй каталог в том же изменении, где элемент темы добавляется, меняется (значение, название, параметры, где используется) или удаляется. Это касается и планов: элемент, заложенный в план, вносится в каталог со статусом «план».
